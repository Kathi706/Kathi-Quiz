Einstellungen

Die App kostet nichts und benötigt weder Abonnement noch KI-Schlüssel. Deine Antworten bleiben nur in diesem Browser gespeichert. Bildsuchbegriffe werden für die Darstellung echter Bilder an Wikimedia Commons gesendet.

Kostenloses Quiz verfügbar

Kostenloses Hosting über GitHub Pages oder Vercel Hobby möglich. Weitere Fragerunden können kostenlos als JSON-Datei ergänzt werden. Für Fotos wird eine Internetverbindung benötigt. Nach Erschöpfung der vorinstallierten Runden entstehen nicht automatisch neue KI-Fragen.
